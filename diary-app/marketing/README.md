## איך לייצר מחדש

התיקייה `source/` מכילה את קבצי ה-HTML שמהם נוצרו הסרטון והתמונות:

- `promo.html` הוא הסרטון כאנימציית HTML.
- `frames.mjs` הופך אותו לפריימים (Playwright).
- ffmpeg מחבר את הפריימים לסרטון:
  ```
  ffmpeg -framerate 30 -i fr/f%05d.jpg -c:v libx264 -pix_fmt yuv420p promo.mp4
  ```

הקבצים מצפים לתיקיות `fonts/` (גופן Rubik מ-Google Fonts), `logo.png` ו-`shots/` לידם.

### קריינות, כתוביות ומוזיקה
התיקייה `source/voice/` מכילה את הסקריפטים של הקריינות:

| קובץ | מה הוא עושה |
|---|---|
| `promo.json`, `demo.json`, `recap.json` | הטקסט שנאמר והכתוביות של כל סרטון |
| `tts.py` | מייצר קובץ קול לכל משפט (קול עברי של Google) |
| `music.py` | מייצר מוזיקת רקע מקורית, בלי בעיות זכויות |
| `mix.py` | ממקם כל משפט בזמן שלו ומנמיך את המוזיקה בזמן הדיבור |
| `caps.mjs` | מצייר את הכתוביות |

כדי לשנות טקסט: עורכים את קובץ ה-JSON ומריצים שוב.

**לגרסה מקצועית:** אפשר להחליף את הקול הממוחשב בקריין אמיתי, או בקול AI מתקדם יותר כמו ElevenLabs, ולהשאיר את כל השאר כמו שהוא.
