# 📔 היומן שלי — אפליקציית יומן קולי לאנדרואיד ואייפון

אפליקציה שבה מקליטים כל ערב איך היה היום. היא שומרת הכל בארכיון עם תאריך ושעה מדויקים, זוכרת את האנשים שהזכרת ומה הם אמרו לך, ובונה עם הזמן היסטוריה של החיים שלך.

## מה יש באפליקציה

| מסך | מה הוא עושה |
|---|---|
| 🎙️ **היום** | כפתור הקלטה גדול, תיבת טקסט (אפשר להכתיב בקול דרך 🎤 במקלדת), בחירת מצב רוח, זיהוי אוטומטי של שמות ושל "מה אמרו לך", וכרטיס "זוכר את זה?" עם יום מהעבר |
| 📚 **ארכיון** | כל הרשומות לפי יום, עם שעה מדויקת עד השנייה, חיפוש לפי מילה או שם, וסינון לפי אדם. אפשר לנגן הקלטות, לערוך ולמחוק |
| 🗓️ **לוח שנה** | חודש שלם עם אימוג'י מצב רוח בכל יום מתועד, הוספת אירועים / ימי הולדת / ימי נישואין (גם כאלה שחוזרים כל שנה) עם התראה ביום עצמו, ורשימת "בקרוב" |
| 👥 **אנשים** | כל מי שהזכרת: כמה פעמים, מתי לאחרונה, ציר זמן ומשפטים שאמרו לך. בנוסף כרטיס "מה אני כבר יודע עליך" |
| 🎮 **משחק** | משחק זיכרון על החיים שלך: "מי אמר את זה?", "השלם את השם החסר", "את מי פגשת ביום הזה?", "מתי הזכרת את X לאחרונה?". יש חיים ❤️, טיימר, קומבו 🔥, ניקוד, XP ורמות. יש גם משחק דמו |

### התראות
- 🌙 **כל ערב בשעת השינה** (ברירת מחדל 22:30): "איך היה היום?"
- ☀️ **בבוקר שאחרי**: סיכום של אתמול, את מי פגשת ומה אמרו לך
- 🎂 **ביום של אירוע** מלוח השנה

את השעות משנים בהגדרות (⚙️ במסך "היום").

🔒 כל המידע נשמר רק על הטלפון. שום דבר לא נשלח לשרת.

## איך מריצים על הטלפון (הדרך הכי מהירה)

1. מתקינים במחשב [Node.js](https://nodejs.org) (גרסה 20 ומעלה).
2. מתקינים בטלפון את **Expo Go** מ-Google Play או מה-App Store.
3. בטרמינל:
   ```bash
   cd diary-app
   npm install
   npx expo start
   ```
4. סורקים את קוד ה-QR שמופיע: באנדרואיד מתוך Expo Go, ובאייפון עם המצלמה.

## בניית אפליקציה אמיתית להתקנה / לחנויות

```bash
npm install -g eas-cli
eas login
eas build --platform android   # קובץ APK/AAB לאנדרואיד
eas build --platform ios       # לאייפון (צריך חשבון Apple Developer)
```

## מבנה הקוד

```
App.tsx                    ניווט תחתון + פתיחת מסך מתוך התראה
src/lib/store.tsx          שמירת כל הנתונים על המכשיר (AsyncStorage)
src/lib/names.ts           זיהוי שמות בעברית (כולל תחיליות ו/ה/ב/ל…) וחילוץ "X אמר/ה ש…"
src/lib/notifications.ts   תזכורת לילה, סיכום בוקר ותזכורות לאירועים
src/lib/game.ts            יצירת שאלות למשחק מתוך היומן
src/lib/audio.ts           שמירת הקלטות לתיקייה קבועה
src/screens/*              חמשת המסכים
src/components/*           מקליט, חלון רשומה, הגדרות ורכיבי עיצוב
```

## הערה על תמלול
ההקלטה נשמרת כקובץ קול שאפשר לנגן מהארכיון. כדי שהאפליקציה תזהה שמות היא צריכה טקסט, ולכן הכי נוח ללחוץ על כפתור המיקרופון במקלדת של הטלפון ולהכתיב. זה עובד בעברית גם באנדרואיד וגם באייפון. אפשר להוסיף בהמשך תמלול אוטומטי של ההקלטה עצמה (למשל עם `expo-speech-recognition`), אבל זה דורש Development Build ולא ירוץ ב-Expo Go.
