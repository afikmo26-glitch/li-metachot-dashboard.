# 🤖 שרת ה-AI של היומן (Claude)

השרת הקטן הזה נותן ל"יומי" ול"מקום לפרוק" לענות כמו בן אדם אמיתי. מפתח ה-Claude שמור בשרת בלבד ולא נכנס לאפליקציה, כך שאף אחד לא יכול לגנוב אותו מתוך קובץ ההתקנה.

אפשר להקים הכל **מהטלפון**, בלי מחשב.

> **לשימוש אישי לא צריך שרת:** פותחים מפתח Claude (שלב 1 למטה) ומדביקים אותו באפליקציה תחת ⚙️ הגדרות ← צ'אט חכם ← מפתח Claude אישי. השרת נחוץ רק אם רוצים שחברים ישתמשו ב-AI בלי מפתח משלהם.

## 1. מפתח Claude
1. נכנסים ל-https://console.anthropic.com ופותחים חשבון.
2. **Billing**: מוסיפים אמצעי תשלום וטוענים קרדיט (למשל 5$).
3. **API Keys** ← **Create Key** ← מעתיקים את המפתח (מתחיל ב-`sk-ant-`). שומרים אותו בצד.

## 2. השרת ב-Cloudflare (חינם)
1. נכנסים ל-https://dash.cloudflare.com ופותחים חשבון חינמי.
2. **Workers & Pages** ← **Create** ← **Import a repository** ← מחברים את GitHub ובוחרים את `li-metachot-dashboard.`.
3. בהגדרות הבנייה:
   - **Production branch**: `claude/personal-diary-archive-app-cs78gt`
   - **Root directory**: `diary-app/server`
   - **Deploy command**: `npx wrangler deploy` (ברירת המחדל)
4. לוחצים **Deploy** ומחכים שיסיים.
5. בתוך ה-Worker החדש: **Settings** ← **Variables and Secrets** ← מוסיפים שני **Secret**:
   - `ANTHROPIC_API_KEY` = המפתח משלב 1
   - `APP_KEY` = סיסמה ארוכה שאתה ממציא (למשל 20 תווים מעורבבים)
6. מעתיקים את כתובת השרת (נראית כמו `https://diary-ai.<שם>.workers.dev`).

## 3. חיבור האפליקציה
באפליקציה: ⚙️ הגדרות ← **צ'אט חכם (AI)** ← מדביקים את כתובת השרת ואת ה-`APP_KEY` ← **בדוק חיבור**.

## עלות
המודל הוא Claude Opus 5.5. הודעה בצ'אט עולה בערך 1–3 סנט, וכתיבת רשומה ביומן בסוף שיחה עוד כמה סנטים. אפשר להגדיר תקרת הוצאה חודשית ב-console.anthropic.com תחת **Limits**.

## פרטיות
כשה-AI פעיל, ההודעות של הצ'אט נשלחות לשרת שלך ומשם ל-Claude. ב"מקום לפרוק" נשלח רק השם שלך ותוכן השיחה, בלי היומן. אפשר לכבות את ה-AI בנפרד לכל אחד מהם בהגדרות.
